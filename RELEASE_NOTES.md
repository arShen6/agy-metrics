# tokens-tips v0.2.3

**See token usage, context fill, generation speed and first-token wait inside Antigravity Desktop.**

**在 Antigravity 输入框旁查看 token 用量、上下文占用、生成速度和首字等待。**

## Download & install / 下载与安装

Choose `en.zip` for English explanations or `zh-CN.zip` for Chinese. Extract the whole ZIP, then double-click **`install.command`**. The runtime is included; no separate setup commands are needed.

选择英文或中文安装包，完整解压后双击 **`install.command`**。内置运行环境，无需另装 Node 或手输命令。

For **macOS Apple Silicon (M series)**. Reference client: Antigravity 2.32.1. Starts at login, runs in the background, and includes status, language-switching and uninstall launchers.

适用于 **macOS M 系列**，参考适配版本 Antigravity 2.32.1；登录自动启动，附带状态检查、语言切换和卸载入口。

This release unifies the name as **tokens-tips** and makes the README English-first with Chinese alongside. Metrics calculations are unchanged. The compact strip stays in English; tooltips follow your chosen language.

本版统一名称为 **tokens-tips**，README 改为英文优先、中英文同页，突出指标展示与快速安装；指标计算保持不变。

The installer is not Apple-signed or notarized; macOS may request confirmation. This is an unofficial local UI patch, and future client updates may require compatibility fixes.
